I bridge the gap between network infrastructure and software engineering, crafting high-performance, secure, and user-centric web applications.

Hello there

Hi, I'm Abdul Ahad - a network engineer turned software engineer crafting efficient digital solutions.

I started my journey in the IT world as a network engineer, configuring routers, switches, and security policies. Over the course of three years, I optimized network infrastructure and secured systems, earning my Cisco Certified Network Associate (CCNA) credential.

Recognizing the power of automation and web platforms, I transitioned into software development. Today, I combine my deep understanding of networking protocols and system architecture with modern frontend and backend technologies to build robust, scalable applications.
